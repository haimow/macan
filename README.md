# Maçan Real Estate — TV Sunum

GitHub Pages üzerinden çalışan, bilgisayarsız TV sunumu.

## Klasör Yapısı

```
/
├── index.html        ← sunum dosyası
└── images/
    ├── gorsel-1.jpg
    ├── gorsel-2.jpg
    └── gorsel-3.jpg
```

## Yeni Görsel Eklemek

1. `images/` klasörüne görseli yükle
2. `index.html` içindeki `IMAGES` dizisine dosya adını ekle
3. Kaydet — TV'de otomatik güncellenir
